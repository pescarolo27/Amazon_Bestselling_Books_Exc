# Amazon Bestselling Books (Excel)

**The Data:** The dataset is a collection of data related to the top 50 best-selling books on Amazon for each year between 2009 & 2019 ([Kaggle])(https://www.kaggle.com/datasets/sootersaalu/amazon-top-50-bestselling-books-2009-2019). The data, containing 550 books, has been categorized into fiction & non-fiction using Goodreads. In the Excel file, there are various sheets containing notes about the dataset, the original dataset, modified versions of the data, analyses, & a final dashboard ("Dashboard (1)").

**Purpose:** An Excel dashboard was created to display relevant metrics such as book appearances, authors, prices, reviews, & more.
